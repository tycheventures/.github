# Tyche Ventures — static site

Static HTML/CSS export of the Tyche Ventures site, ready for GitHub Pages.

- `index.html` — homepage
- `about.html` — about page
- `assets/style.css` — compiled stylesheet
- `assets/site.js` — vanilla JS (mobile menu, counters, testimonial slider)
- `img/` — all images and logos
- `.nojekyll` — disables Jekyll processing

## Publish
Repo Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / folder: `/docs`.
